=============================================================================
DevPulse — Standard Web Application Run & Build Commands
=============================================================================

1. Database Commands (Prerequisite for Backend)
DevPulse uses MySQL with automated Flyway schema migrations.

# Start MySQL container in the background
docker-compose up -d

# Check database container status
docker-compose ps

# View database logs (useful to verify startup)
docker-compose logs -f

# Stop the database container
docker-compose down

-----------------------------------------------------------------------------
2. Run the Spring Boot Backend
The backend runs independently on port 8081.

# From root directory:
npm run dev:backend

# Or from backend directory:
cd backend
mvn spring-boot:run

Backend API Base: http://localhost:8081
Swagger / OpenAPI Documentation: http://localhost:8081/swagger-ui.html
API Docs JSON: http://localhost:8081/api-docs

-----------------------------------------------------------------------------
3. Run the React Web Frontend
Starts the Vite dev server with Hot Module Replacement (HMR).

# From root directory:
npm run dev

# Or from frontend directory:
cd frontend
npm run dev

Web App URL: http://localhost:5173

-----------------------------------------------------------------------------
4. Build the Web Application
Compiles TypeScript and creates optimized production web bundle.

# From root directory:
npm run build

# Or from frontend directory:
cd frontend
npm run build

Production output is generated in frontend/dist/.
Preview production build: npm --prefix frontend run preview

-----------------------------------------------------------------------------
5. Helpful Development & Testing Commands

# Run Frontend Tests (Vitest)
npm test

# Run Backend Integration Tests (Maven / JUnit)
npm run test:backend

# Lint Frontend Code
npm --prefix frontend run lint

-----------------------------------------------------------------------------
6. Typical Local Workflow Summary
Open two terminal tabs:

Tab 1 — Database & Backend:
docker-compose up -d
npm run dev:backend

Tab 2 — Web Frontend:
npm run dev
(Open http://localhost:5173 in your browser)
